1 вы добавляете в эту папку файлы или изменяете их прямо в этой папке. потом пишите git add -A
то есть теперь изменения в папке отслеживаются. 
2 Затем вы делаете коммит git commit -m "..."
3 затем пушите изменения на гитхаб git push origin main
перед пушем вы можете сделать сколько угодно коммитов, то есть можете несколько раз повторять шаги 1 и 2
и потом уже пушить их на гитхаб то есть можно запушить несколько коммитов сразу, чтобы по чуть-чуть не отправлять.
